# tobymarks/tap

Homebrew tap for [inlaut](https://inlaut.de/en), a free, open-source macOS menu bar dictation app with on-device speech recognition for German and English.

```bash
brew install --cask tobymarks/tap/inlaut
```

Requires a Mac with Apple silicon and macOS 26 or later. The disk images are the same Developer ID signed and notarized ones as on [the releases page](https://github.com/tobymarks/inlaut/releases); the app updates itself through Sparkle.
